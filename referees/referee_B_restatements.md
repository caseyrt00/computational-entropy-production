## Verdict

**Minor corrections.** Every theorem, lemma and proposition in the joint is correct as stated, and every quantifier I compared against a source matches or is a harmless paraphrase (no quantifier mismatch; two citation-pointer mismatches, table rows 17 and 29); the most important finding is that Definition 9 points the reader to a "Lemma 7" of GKLO22 that does not exist (the proof of their Lemma 26(1) uses Lemma 6), and Proposition 2's stated reason for its Proved-conditional label is wrong in the paper's favour: the specialisation it says it needs is stated verbatim in the source.

No BLOCKING or MAJOR finding. The one check that could have produced a MAJOR (whether the paper's own sources already give DistNP ⊆ AvgBPP ⇒ hypothesis (i) of Proposition 8, which would collapse the "two incomparable tops") resolves in the paper's favour; see Verified item V21.

### MINOR

**M1. Definition 9 (L563) cites a lemma that does not exist.** Text: "in the errorless sense of §7.1, the sense in which that proof feeds (L, D) to their Lemma 7." GKLO22's numbering runs Definition 4 (`gklo_ccc2022.txt:684`), Definition 5 (`:701`), Lemma 6 (`:717`), Theorem 7 (`:781`, a result on PH and AvgBPP from [18]); there is no Lemma 7. The proof of Lemma 26(1) uses Lemma 6: "Using the assumption that DistNP ⊆ AvgBPP, it follows that (L, D) ∈ AvgBPP. Let B be a randomized algorithm for (L, D) as in Lemma 6." (`:1367–1370`). Fix: "feeds (L, D) to their Lemma 6". The same pointer is correct in Proposition 3's preamble (L569, "the Lemma-6 algorithm").

**M2. Proposition 2 preamble (L527): the reason given for the Proved-conditional label is factually wrong.** Text: "because Lemma 26 is used in a specialisation (no auxiliary string) of the form in which the source states it, whereas Theorem 3(b) uses HILNO's Theorem 4 exactly as stated." The source states the specialisation: "Moreover, the special case without conditioning on r also holds for both items above, i.e., when r is the empty string (for τ = 0) and y is an arbitrary single string." (`gklo_ccc2022.txt:1355–1356`). So Lemma 26(1) is used exactly as stated, in the sentence following its two items. Fix (either): upgrade to **Proved** "from [GKLO22, Lemma 26(1) and the sentence following it, p. 16:22, Read]"; or keep Proved-conditional and give the true reason, that the source's proof was not re-derived here. Proposition 3(a) (L571, "in the special case with no conditioning string") should cite the same sentence.

**M3. Proposition 2(a) statement (L531) fixes P(s) := p(cs); the proof delivers the Σ⁺ bound at P(s) = p(cs + O(n)).** Text of the proof (L539): "the O(1)-bit, O(n)-time re-encoding puts the reverse-order parts at time p(cs + O(n)) rather than p(cs), which only lowers Σ⁺ by Lemma 4, so it is absorbed by enlarging P." Enlarging P is correct (Σ⁺_{s,P} is non-increasing in P by Lemma 4), but the statement does not enlarge it: with P(s) = p(cs) exactly, the chain (H2)-then-(E1) is for the pair in the order (y, x), and Lemma 11 gives the pair in the order (x, y). Fix: state "P(s) := p(c′s) for a constant c′ ≥ c depending only on U", using s ≥ n to absorb the O(n); or add to Lemma 11 the one-line remark that its constant c also covers printing the pair in either order. Proposition 8(b) (L739) inherits the same choice and the same fix.

**M4. Three formulations of pK^t are chained without a bridging sentence.** Definition 1 (L70–76) is HILNO's eq. (6), a Turing machine with y on a separate tape (`hilno_eprint2023-424.txt:815–830`). GKLO22's Definition 17 is a RAM machine M(w, y) (`gklo_ccc2022.txt:1078–1091`, footnote 18 at `:1095–1100`, which says a TM with two tapes is an admissible alternative). KK25 define pK^t(x | y) ≤ s as K^t(x | y, r) ≤ s for 2/3 of r ∈ {0,1}^t (`kk_eccc_tr25-089.txt:206`). Proposition 2(a) chains (H1)/(H2), taken from GKLO's measure, with (E1)/(E2) from Lemma 11, proved in the paper's measure (and Lemma 11 applies GKLO's Lemma 21 to Definition 1 directly, L394); Proposition 8(a) chains KK's measure with the same (E1)/(E2). The three measures agree up to O(1) additive bits and a polynomial change of t (mutual simulation), which the polynomials p, P and the O(log s) slack absorb. That is true and easy [Inference: GKLO's footnote 18 gives the TM/RAM interchangeability; the O(1)-bit, polynomial-time quantification is mine, not read], but the paper, whose stated standard is quantifier exactness, never says it. Fix: one sentence in §2.1: "GKLO22's Definition 17 (RAM machine) and KK25's formulation differ from Definition 1 by O(1) bits and a polynomial in t; every use of their results below survives that change, and the polynomials p and P absorb it."

**M5. Lemma 9's plain reading (L327) drops the infinitely-often qualifier.** Formula: "For every constant c, every polynomial q and every polynomial t, for infinitely many n, Pr_z[…] < 1/q(n)." Plain reading: "for a one-way function, a random input almost never has a fast description from its output that is within c log n bits of the counting bound." As written it reads as an almost-everywhere statement. Fix: "…within c log n bits of the counting bound, for infinitely many input lengths."

**M6. "Never lies" overstates the errorless notion in two places.** §7.1 (L517): "answers 'I don't know' on at most an ε fraction of the instances and never lies"; Definition 9's plain reading (L567): "is right on most inputs, and never lies (it may say 'I don't know')." GKLO22's Definition 5, item 1: "for every n, δ > 0, and every x ∈ supp(D_n), Pr_{r_A}[A(x; n, δ) ∉ {L(x), ⊥}] ≤ 1/4" (`gklo_ccc2022.txt:701–706`): a randomized errorless heuristic may lie with probability up to 1/4 over its own coins on every input; amplification (footnote 14, `:767–768`; proof of Lemma 6) brings this to 1/n, never to 0. Fix: "and lies only with small probability over its own coins, on every input" (or "never lies, up to the randomized error 1/4 that GKLO22's Definition 5 allows"). The same qualifier belongs in the plain reading of Proposition 8(b) (L741), "never says 'no' to a string with a short program": the BPP version accepts such strings with probability at least 0.9 (`kk_eccc_tr25-089.txt:680–683`, and Definition 2.11's last sentence `:691`).

### NIT

**N1. §7.6 (L729) and the reference entry for Ilango–Ren–Santhanam (L1030) cite "[HILNO, §2, Read]" / "HILNO §2, p. 12".** The passage ("Under the assumption that there is no one-way function, it was shown in [IRS21] that for every polynomial-time samplable distribution D, there exists an efficient average-case algorithm A that approximates the resource-unbounded Kolmogorov complexity K(x) of a string x ∼ D") is at `hilno_eprint2023-424.txt:579–583`, in §1.3 Techniques, page 12 (page marker at `:594`); §2 Preliminaries begins at `:760` (p. 16). Fix: "§1.3, p. 12".

**N2. Theorem 2, "Not new" sentence (L321): "packaged in expectation form, and nothing more" overstates the packaging.** The direction (2) ⇒ (1) is not obtainable from HILNO's Theorem 1 as a black box: Markov on the mean, after Lemma 7 controls the negative part, gives pK^t(x | y) ≤ log 1/D(x | y) + O(q(n) log n) on a 1 − 1/q(n) fraction, a polynomial additive term where item 3 needs log p(n). The paper does the right thing, re-running HILNO's Lemma 20 mechanism on the one-way-function distribution (Lemma 9, `hilno_eprint2023-424.txt:1283–1319`). Fix: "(1) ⇒ (3) as stated, and HILNO's Lemma 20 argument for the converse".

**N3. pK^t of a pair is never given a convention.** Definition 1 indexes the time and the random tape by |x| (t(n), r ∈ {0,1}^{t(n)}); pK^t(x, y) first appears in Lemma 11 (L388) and is then chained with pK^s(x) in Definition 8 and Proposition 2 with t treated as a bare number. Fix: one line in §2.1 fixing the pairing and reading t as a number (or as t(2n)); nothing downstream changes.

**N4. Definition 3 (L88–90) versus HILNO eq. (5).** HILNO: "Pr_{x∼{0,1}^n}[f(A(1^n, f(x))) = f(x)] ≤ n^{−c}" for every PPT A and constant c ≥ 1, infinitely often for the i.o. version (`hilno_eprint2023-424.txt:776–780, 793–794`). Paper: A(f(z)) ∈ f^{−1}(f(z)) with "< 1/q(n)". Equivalent (1^n is recoverable from |f(z)| for the length-preserving f the paper fixes; "for every c, ≤ n^{−c} i.o." and "for every q, < 1/q(n) i.o." imply each other). No change needed; a parenthesis "(HILNO write A(1^n, f(x)) and ≤ n^{−c}; equivalent)" would close the gap for a reader comparing.

**N5. Definition 9's plain reading (L567) omits L's time bound and slightly misstates its length condition.** L asks for a program of length exactly s = |u| + |v| − 10 that prints uv "in |w| steps" (`gklo_ccc2022.txt:1358–1360`); the plain reading says "a description … ten bits shorter than itself" and says nothing about the running time being the length of the first helper string. Fix: "…has a program exactly ten bits shorter than itself that prints it, given the helpers, within as many steps as the first helper is long".

**N6. §7.6 (L727): "the two kinds of scheme are known to coincide only for problems that admit an instance checker."** Hirahara reports Hirahara–Santhanam's equivalence "of any problem that admits an instance checker" (`hirahara_ccc2022_lipics234-26.txt:164–166`), a sufficient condition; "only" is the paper's gloss. Also, Theorem 1.3's chain 2 ⇒ 3 ⇒ 4 is under "E ⊄ i.o.SIZE(2^{εn})" (`:148–149`); the paper's plain reading (L725) acknowledges the circuit-lower-bound assumption, the sentence itself does not. Fix: "known to coincide for problems that admit an instance checker [HS22 via Hirahara 2022]" and "under a circuit lower bound for E".

**N7. Theorem 2, proof of (2) ⇒ (1), display at L351.** The stated bound "(c − 3) log n − 2 log 3 − 4 − c log n / n" is valid but loose: the computation gives (c − 2) log n − 2 log 3 − 4 − c log n / n (using L = log(3(n + d)/2) ≤ log n + log 3 for n ≥ d, so 2(L + 2) ≤ 2 log n + 2 log 3 + 4). Checked numerically for d ∈ {1, 5, 20}, n ≤ 5000, c ∈ {1, 4, 10, 50}: exact − paper ≥ 0 throughout. No action needed; recorded so nobody "corrects" it the wrong way.

## In plain words

The parts of the paper I was asked to check are right. The restatement of the Hirahara–Ilango–Lu–Nanashima–Oliveira duality as "one-way functions exist exactly when some fast process has a large average production" is proved correctly in both directions, and every "for all", "there exists", "infinitely often" and "for almost all" I compared against the five source papers is the same as in the source or a harmless rewording. The two-sided comparison (Theorem 3) and the sandwich around the open problem (Propositions 2, 3 and 8) are also correct, and the one thing that could have been a serious problem, that the paper's two "top" hypotheses might secretly be one, is not: the sources genuinely do not connect them, for the reason the paper gives. What is wrong is small and clerical: one pointer to a lemma that does not exist in the cited paper (it should be Lemma 6, not Lemma 7); one label that is more cautious than it needs to be and gives a wrong reason for the caution (the source states the special case the paper thought it was borrowing); one place where the statement of a proposition fixes a time budget slightly smaller than its own proof delivers; a missing sentence saying that three papers' slightly different definitions of the description measure agree up to constants; and four plain-language readings that say "never" or "almost never" where the formula says "for infinitely many lengths" or "with small probability". Each fix is a sentence or a phrase; the whole set is under an hour of editing, and none of it changes a theorem.

## Appendix: the check script (rerunnable)

Run with the project interpreter: `.venv/bin/python - <<'PY' … PY` with the text below, or save it as `check_identities.py` and run `.venv/bin/python check_identities.py`. Runtime under one second. Expected output: `identities: OK`; `Theorem 2 lower bound: min(exact - paper) over n>=d = 0.0`; `Theorem 3(a): max over n>=d of L-(log n+2) = -0.415…`; `1/ln 2 = 1.4426… <= 2: True`.

```python
import random, math
random.seed(1)
# Lemma 10 / Def 8 identities with arbitrary integer values of the four pK terms
for _ in range(1000):
    Kx, Ky, Kxy, Kyx = [random.randint(0, 200) for _ in range(4)]   # pK(x), pK(y), pK(x|y), pK(y|x)
    mF = -(Kx + Kyx); mR = -(Ky + Kxy)                                # log m_F, log m_R
    sigma = mF - mR
    assert sigma == (Ky + Kxy) - (Kx + Kyx)                           # Def 6
    assert sigma == (Ky - Kyx) - (Kx - Kxy)                           # Lemma 10(iii) line 1
    assert sigma == (Kxy - Kyx) - (Kx - Ky)                           # Lemma 10(iii) line 2
    # antisymmetry: swap roles x<->y: pK(y), pK(x), pK(y|x), pK(x|y)
    sigma_swapped = (Kx + Kyx) - (Ky + Kxy)
    assert sigma_swapped == -sigma                                    # Lemma 10(ii)
    # Def 8: Sigma^-(x,y) = Sigma^+(y,x) with long-time values primed
    PKx, PKy, PKxy, PKyx = [random.randint(0, v) for v in (Kx, Ky, Kxy, Kyx)]  # pK^{P(s)} <= pK^s (Lemma 4)
    Splus  = (PKy + PKxy) - (Kx + Kyx)
    Sminus = (PKx + PKyx) - (Ky + Kxy)
    Splus_swapped = (PKx + PKyx) - (Ky + Kxy)   # Sigma^+(y,x)
    assert Sminus == Splus_swapped
    assert Splus <= sigma and Sminus <= -sigma                         # Prop 2(b)
print("identities: OK")

# Theorem 2 (2)=>(1): paper's bound (c-3)log n - 2log3 - 4 - c log n/n  <=  exact  c log n (1-1/n) - 2(L+2), L=log2(3(n+d)/2)

print("Theorem 2 lower bound: min(exact - paper) over n>=d =", round(worst, 6), "(>= 0 means paper's bound is valid)")
```
